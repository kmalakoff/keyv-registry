    Function migrateKeyv5Keys

    • migrateKeyv5Keys(store: Keyv): Promise<number>

      One-time move of entries keyv 5 wrote under its default keyv namespace to the plain keys keyv 6 reads.

      Works through the Keyv API only, on the instance the caller passes, so it covers every adapter that can iterate. Finds both old layouts: keyv:<key> with no namespace (keyv-file) and namespace keyv (sqlite <key>, redis keyv:<key>). Keeps the absolute expiry, skips expired entries, lets an existing plain key win, and is safe to run again.

      Call it at startup, before the store serves other traffic: it renames keys and switches store.namespace while it runs. A plain key that itself starts with keyv: is taken for a keyv 5 key. A store that cannot iterate (for example memcache) has nothing to find: it returns 0.

      Store errors: keyv hides them from the caller once any error listener is attached, so a temporary listener watches every read and write. If one is emitted, the old key is not deleted and the call rejects with the error as cause; entries already moved stay moved and a rerun repairs the rest.
